intent* — "deliver" | "personal"

Persisted via PUT /rider/profile (UpdateProfileRequest(intent)). Exactly one selection is required; nothing else is asked on this screen.

Behavior contract

  • Selection cards replace small radio rows: 64dp minimum height, icon chip + title + one-line description, single-select with animated check.
  • Continue is disabled until a card is chosen — the disabled style is the neutral token pair, never red.
  • Info banner stays on-screen: switchability later + commercial-verification caveat (honest expectations).
  • Double-tap race guard from ONBOARDING-AUDIT P1-4 is preserved: submitting state blocks re-entry.
  • Session-missing fallback keeps the toast error path (riderId == null).
