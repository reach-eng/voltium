Splash screen

Brand reveal on cold launch. Centered Voltium mark, the "Ride electric. Earn smarter." tagline and a progress bar that runs once. Returning users with a valid session see a 300ms beat instead — see PR-VER-2026-08-07.

What this screen does

  • Shows the Voltium logo, name and tagline.
  • Precaches assets in didChangeDependencies.
  • Checks for a stored session and short-circuits for returning users.
  • Fires PostHog splash_viewed for analytics.
